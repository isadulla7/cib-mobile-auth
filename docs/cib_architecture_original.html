📝 Registration Oqimi

1
📞 Telefon raqam kiritish
validatsiya → OTP yuborish (Dynamic Notification)
2
🔢 OTP tasdiqlash
5 xonali, 120 sek, max 3 urinish — DB config'dan
3
👤 PINFL + Pasport + Tug'ilgan sana
MyID/DIA tashqi tekshiruv → yosh 18+ tekshiruv
4
🔒 Parol yaratish
Kuchlilik tekshiruv (DB rules) → BCrypt hash (STATIC)
5
⚫ PIN kod yaratish
4 xonali (DB config) → AES shifrlash (STATIC)
✅ User yaratildi → JWT → Home. Barcha step'lar DB'dan keladi.

🔑 Login Oqimi

1
📱 Login usulini tanlash
Telefon yoki PINFL — DB: login_methods config'dan
2
🔒 Parol tekshirish
BCrypt.matches (STATIC) → 5 xato = bloklash (DB config)
3
📱 Qurilma tekshirish
Yangi qurilma? → OTP tasdiqlash talab qiladi
4
⚫ PIN kod so'rash
PIN o'rnatilganmi? → so'ra. Yo'q → o'rnatdir
5
👆 Biometrika
Mavjud? → sozlashni taklif qil (DB: biometric_enabled)
✅ JWT token → Home. Post-login qadamlar DB'dan — tartib o'zgartiriladi.
