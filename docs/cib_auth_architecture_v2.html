Trusted device

Risk past bo‘lsa OTP skip qilinishi mumkin — policy bo‘yicha.

New device

OTP/MFA + device binding. Device identity authentication factor emas, risk signal sifatida ishlatiladi.

Suspicious

Throttle, step-up MFA, temporary deny, audit alert. Generic error response saqlanadi.

11. Eng muhim failure-case’lar

OTP brute-force

Atomic attempts + per-IP/per-identity throttling + challenge expiration.

User enumeration

“Bu telefon mavjud” kabi farqli auth errorlarni login endpointda bermaslik.

Config race

Client policyVersion yuboradi; server stale policy bo‘lsa controlled refresh qaytaradi.

Step skipping

Client state authoritative emas; server-side state machine transitionni tekshiradi.

Refresh replay

Refresh token rotation + family/reuse detection → family revoke.

Provider outage

MyID/SMS adapter timeout + retry policy + circuit breaker + safe state.

12. Final design decision

CIB Auth V2: Backend-driven UI + Versioned Policy Engine + Server-side Auth State Machine + Allowlisted Registry + Redis Ephemeral State + Oracle Durable State + Device/Risk-aware Session Lifecycle.
